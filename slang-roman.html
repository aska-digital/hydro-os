hydro-os

Arey miyaan! Ye Omarchy ke upar apna khaas layer hai. Charminar ko Shahid miyaan ki apni machine banata. Poora set, bhaari!

Neeche poora asli Omarchy hai, haath lagaya hi nahi! Jo bhi change hai, sab yahan ich likha pada hai. Nishaan laga ke, lock kar ke. Tension nakko lo miyaan, machine hallu hallu maze mein chalti rehti.

Layer utha lo miyaan! Lagana kaisa?
Pin: Omarchy 4.0.4 Machine: Charminar Team: hydro-team

Ye kya hai

Suno miyaan, ye fork-work kuch nahi hai!

Is repo mein woh sab changes hain jo stock Omarchy ko Shahid miyaan ki machine, Charminar banate. Base system? Arey usko humne dekha tak nahi! Block, launcher, script, sab yahan ich pade hain, nishaan lage hue. Upgrade aaye toh ghabrana nakko. Tum khaali baith ke ek char chai piyo!

  • Pin base. VERSION file mein Omarchy ka poora bio-data likha hai. Upgrade kare toh isko bhi update karna. Bhoolna nakko, kya samjhe?
  • Ek ich michine. Charminar: Omarchy Linux, Hyprland, Wayland. Poora package, bhaari setup, kirak! Yahaan ki har cheez isi ke naap ki bani.
  • Ek ich team. hydro-team: hyd-nawab aur hyd-nizam. Nawab miyaan CRM ke ustad. Nizam miyaan machine pe agent bithane wale. Dono pakke Hyderabadi, kya samjhe?
  • Chhota rakho miyaan. Omarchy ke andar ghus ke patch maarne ka scene nikla toh woh fork wali film hai. Pehle Shahid miyaan se permission lena, hau!

Install

Clone karo, script chalao, Shahid ban ke, hau! Root ban ke chalaya toh samjho gaye miyaan! Aise baigan ke batan nakko karo!

terminal
# get the layer
git clone https://github.com/aska-digital/hydro-os.git
cd hydro-os
terminal
# apply a Hyprland block: removes the old block first,
# backs up, verifies, restores on failure
bash scripts/apply-hyprland-block.sh rhino-crm

# install an app-menu launcher
bash scripts/install-launcher.sh rhino-crm

Apply script pehle Hyprland --verify-config se check karta, phir reload maarta. Fail hua toh backup wapas. Jaando, jaise kuch hua hi nahi! Naye button aur window rule agle login pe aate. Reload pe 'abhiich aarum' bol ke intezaar kare toh karti raho, aane ke nahi!

Andar kya hai

Paanch folder. Har ek ka ek hi kaam.

hyprland/

Guard wale block, live config mein aaram se jodte. Har block ke dono taraf nishaan, taaki dobara chalao toh gadbad nakko. SUPER+R dabao, CRM haazir! Aur suno miyaan, SUPER+C ko haath lagaya toh khair nahi. Woh hamesha copy hi rehta. Kya samjhe?

launchers/

App menu ki .desktop files, ~/.local/share/applications mein jaa ke baith jaatin. Har app ki ek, naam block jaisa. Set!

scripts/

One-time setup script. Block lagao, launcher bithao, kaam khatam, bhaari! Backup aur check saath mein free, aisich. Shahid ban ke chalao, sudo ka naam bhi nakko miyaan!

docs/

Bilkul seedhi zubaan mein guide, roz ka hisaab aur safe command. Jo keyboard pe baitha hai na, uski bhi samajh mein aaye aisa!

apps/

Charminar pe kya kya laga hai aur asal repo kahaan hain, poora hisaab-kitaab. Apps khud yahaan nahi miyaan, sirf unke pate hain. Pate le lo, khud jaa ke dekh lo!

Yahaan kya nahi hai

  • CRM ka source code? Arey woh aska-digital/rhino-crm mein hai miyaan! Yahaan kya dhoond rahe?
  • Shahid ka personal data, database, backup, password? Ye sab yahaan nahi hai, aur hona bhi nakko!
  • Stock Omarchy ki cheez? Zero, nil, kuch bhi nahi! Sirf apna layer.

Usool

Chaar usool. Light lo miyaan, machine khush toh tum khush!

  1. Chalta hua CRM band karna nakko miyaan! Haath bhi nakko lagana! /home/muse/crm-os ka server 127.0.0.1:8741 pe chalta rehna chahiye. Tumaku doubt hai toh operating guide padh lo, hau!

  2. Hyprland change ka sahi tareeqa suno: purana block pehle bahar phenko, naya andar daalo, Hyprland --verify-config se check karo, backup jeb mein rakho. Bas!

  3. Testing Charminar pe, Shahid miyaan ke saamne. Reboot ka button unke haath mein hai, hamare haath mein nahi. Kya samjhe?

  4. Chhota rakho, lamba na kheencho miyaan. Yahaan sirf config chalta. Omarchy mein patch maarne ka khayaal bhi aaya na, toh pehle Shahid miyaan se baat kar lena!
