# Charminar: the keys you need

The **Super key** is the key with the Windows logo, next to the space bar.
Hold it down, then press the other key.

| Press | What happens |
|-------|--------------|
| **Super + 1** | WhatsApp |
| **Super + 2** | Gmail |
| **Super + 3** | Google Drive |
| **Super + 4** | Google Meet |
| **Super + 5** | Chromium (the web browser) |
| **Super + R** | Rhino CRM |
| **Super + Space** | The menu. Find and open any app. |
| **Super + W** | Close the window you are looking at |

Each app has its own screen and opens full size.
Pressing its key again jumps back to it.

## Three more, if you need them

| Press | What happens |
|-------|--------------|
| **Super + Escape** | Lock, log out, restart, or shut down |
| **Super + K** | Show the full list of keys on screen |
| **Left Alt + Right Alt** (both together) | Switch keyboard: English, Arabic, Urdu. The top bar shows EN, AR, or UR. |

The screen goes dark after 15 minutes and locks after 1 hour.
Type your password to unlock.
