نیچے پورا اصلی اومارکی ہے، ہم نے اس کو ہاتھ بھی نہیں لگایا۔ جو بھی چینج ہے، سب یہیں لکھا پڑا ہے — نشان لگا کے، لاک کر کے۔ اپ گریڈ آئے تو ٹینشن نکو، مشین مزے میں چلتی رہتی۔

یہ کیا ہے

سنو میاں، یہ فورک ورک کچھ نہیں ہے!

اس ریپو میں وہ سب چینجیں ہیں جو اسٹاک اومارکی کو شاہد میاں کی مشین، چارمینار بناتیں۔ بیس سسٹم؟ اس کو ہم نے دیکھا تک نہیں! بلاک، لانچر، اسکرپٹ — سب یہیں، نشان لگے ہوئے۔ اپ گریڈ آئے تو گھبرانا نکو۔

  • پن بیس۔ VERSION فائل میں اومارکی کا پورا بائیو ڈیٹا لکھا ہے۔ اپ گریڈ کرے تو اس کو بھی اپ ڈیٹ کرنا، بھولنا نکو!
  • ایک ہی مشین۔ چارمینار — اومارکی لینکس، ہائپر لینڈ، وے لینڈ، پورا پیکج۔ یہاں کی ہر چیز اسی کے ناپ کی بنی۔
  • ایک ہی ٹیم۔ ہائیڈرو ٹیم — حیدر نواب اور حیدر نظام۔ نواب سی آر ایم کے باس؛ نظام مشین پہ ایجنٹ بٹھانے والے۔
  • چھوٹا رکھو میاں۔ اومارکی کے اندر گھس کے پیچ مارنے کا سین نکلا تو وہ فورک والی فلم ہے — پہلے شاہد میاں سے پرمیشن!

انسٹال

کلون کرو، اسکرپٹ چلاؤ — شاہد بن کے! روٹ بن کے چلایا تو سمجھو گئے۔

terminal
# get the layer
git clone https://github.com/aska-digital/hydro-os.git
cd hydro-os
terminal
# apply a Hyprland block: removes the old block first,
# backs up, verifies, restores on failure
bash scripts/apply-hyprland-block.sh rhino-crm

# install an app-menu launcher
bash scripts/install-launcher.sh rhino-crm

اپلائی اسکرپٹ پہلے Hyprland --verify-config سے چیک کرتا، پھر ری لوڈ۔ فیل ہوا تو بیک اپ واپس — جیسے کچھ ہوا ہی نہیں! نئے بٹن اور ونڈو رول اگلے لاگ اِن پہ آتے، ری لوڈ پہ انتظار نکو۔

اندر کیا ہے

پانچ فولڈر۔ ہر ایک کا ایک ہی کام۔

hyprland/

گارڈ والے بلاک — لائیو کنفیگ میں آرام سے جوڑتے۔ ہر بلاک کے دونوں طرف نشان، تاکہ دوبارہ چلاؤ تو گڑبڑ نکو۔ SUPER+R دباؤ، سی آر ایم حاضر! اور سنو — SUPER+C کو ہاتھ لگایا تو خیر نہیں، وہ ہمیشہ کاپی ہی رہتا۔

launchers/

ایپ مینیو کی .desktop فائلیں — ~/.local/share/applications میں جا کے بیٹھتیں۔ ہر ایپ کی ایک، نام بلاک جیسا۔

scripts/

ون ٹائم سیٹ اپ اسکرپٹ۔ بلاک لگاؤ، لانچر بٹھاؤ، کام ختم۔ بیک اپ اور چیک ساتھ میں فری! شاہد بن کے چلاؤ، sudo کا نام بھی نکو۔

docs/

بالکل سیدھی زبان میں گائیڈ — روز کا حساب اور سیف کمانڈ۔ جو کی بورڈ پہ بیٹھا، اس کی سمجھ میں آئے ایسا۔

apps/

چارمینار پہ کیا کیا لگا ہے اور اصل ریپو کہاں ہیں — پورا حساب کتاب۔ ایپس خود یہاں نہیں میاں، صرف ان کے پتے!

یہاں کیا نہیں ہے

  • سی آر ایم کا سورس کوڈ؟ وہ aska-digital/rhino-crm میں ہے میاں، یہاں ڈھونڈنا نکو!
  • شاہد کا پرسنل ڈیٹا، ڈیٹا بیس، بیک اپ، پاسورڈ — یہ سب یہاں نہیں، اور اچھا ہی ہے!
  • اسٹاک اومارکی کی چیز؟ زیرو۔ صرف اپنا لیئر۔

اصول

چار اصول۔ ان کو فالو کرو، مشین خوش رہے گی۔

  1. چلتا ہوا سی آر ایم بند کِیا تو۔۔۔ نکو میاں! /home/muse/crm-os کا سرور 127.0.0.1:8741 پہ چلتا رہنا چاہیے۔ ڈاؤٹ ہے تو آپریٹنگ گائیڈ پڑھو۔

  2. ہائپر لینڈ چینج کا صحیح طریقہ: پرانا بلاک پہلے باہر، نیا اندر، Hyprland --verify-config سے چیک، بیک اپ جیب میں۔

  3. ٹیسٹنگ چارمینار پہ، شاہد کے سامنے۔ ریبوٹ کا بٹن ان کے ہاتھ میں، ہمارے نہیں!

  4. چھوٹا رکھو، لمبا نہ کھینچو۔ یہاں صرف کنفیگ چلتا۔ اومارکی میں پیچ مارنے کا خیال بھی آیا تو پہلے شاہد میاں سے بات!
